Directly receive customer payment proof screenshots in your private Google Drive folder. Free, permanent, and secure without exposing private credentials.

Web App URL deployed from Google Apps Script with "Execute as: Me" and "Who has access: Anyone".
1-Minute Setup Instructions:
  1. Create or open a folder in your Google Drive (e.g. name it Blume Arts Payments). Copy the folder URL from your browser address bar and paste it into Payment Screenshot Google Drive Folder URL above.
  2. Open Google Apps Script in your browser and click New project.
  3. Name your project Blume Arts Receiver and replace all code in the script editor with the code in google-apps-script/Code.gs.
  4. Click Deploy > New deployment. Choose Web app (gear icon).
  5. Set Execute as: "Me" and Who has access: "Anyone". Click Deploy and authorize permissions.
  6. Copy the resulting Web app URL (ends in /exec), paste it into Google Apps Script Web App URL above, and click Save Google Drive Destination.
